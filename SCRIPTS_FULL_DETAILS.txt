================================================================================
             BLE LAB - FULL SCRIPT DETAILS + EXTERNAL DEVICE REQUIRED
================================================================================
Every script is listed with:
  PATH     absolute path
  TYPE     BLE | CLASSIC | BOTH | N/A
  ATTACK   attack class
  WHAT     what the script actually does
  USE      how it is used in an attack / test
  DEVICE   external hardware that MUST be connected
  DEPS     software libraries / tools needed
  OUTPUT   files or reports it produces (if any)

Hardware legend:
  [DONGLE]   WHAD ButteRFly nRF52840 USB dongle (VID:PID c0ff:eeee, /dev/ttyACM*)
  [HOST]     built-in or USB Bluetooth adapter via BlueZ (no special dongle)
  [HOST-BR]  built-in or USB BR/EDR (classic) capable adapter via BlueZ
  [TARGET]   the BLE or classic device under test
  [SNIFFLE]  TI CC1352 / CC26x2 Launchpad with Sniffle firmware
  [NRF52-ST] Nordic nRF52840 dongle flashed with SweynTooth driver firmware
  [ESP32]    ESP32 board flashed with Braktooth firmware
  [NEXUS5]   rooted Nexus 5 running InternalBlue (or CYW20735 board)
  [BLUING]   CSR8510-class USB dongle running Bluing firmware
  [MICROBIT] BBC micro:bit or nRF52 with Btlejack firmware
================================================================================

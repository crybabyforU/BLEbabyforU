# SECTION A - CORE LAB SCRIPTS (ble-lab/scripts/)  [21 Python + 1 shell]
################################################################################

1_build_packet.py | Packet crafting (offline) | Builds a byte-exact 36-byte CONNECT_IND with custom Access Address, CRCInit, interval, hop and channel map, then runs BLE spec legality checks; used to craft malformed/arbitrary connection packets.
2_send_packet.py | Rogue central / connection hijack | Opens a live link to the target using attacker-chosen Link Layer parameters (AA, CRCInit, channel map, hop) and proves the rogue-parameter link carries GATT.
4_inject_raw.py | Reactive Link Layer injection | Arms a WHAD injector with 4 trigger strategies to fire a raw CONNECT_IND inside the advertising inter-frame space and seize the connection.
5_scan_then_inject.py | Synchronized hijack | Scans to confirm the target is advertising, releases the dongle, reopens as injector, arms AdvA-matched triggers and watches for the connection to be taken.
6_scan_inject_final.py | Low-latency connection race | Single-instance continuous RX that counts target ADV_INDs and arms triggers without a dongle reopen, minimizing latency for connection interception.
7_connect_lifecycle.py | Hijack + acceptance oracle | Injects CONNECT_IND on advertisement detection, then measures the ADV silence gap to confirm the device accepted the packet and obeyed the 2 s supervision timeout.
8_trigger_sweep.py | Injector calibration | Sweeps AdvA pattern byte offsets 0-30, 3.5 s each, to find the exact hardware offset that makes reactive CONNECT_IND injection fire reliably.
10_prepare_rootcause.py | Injection root-cause probe | Wraps the raw packet as BTLE/BTLE_DATA so prepare() accepts it, then compares manual literal TX vs ReceptionTrigger to test if stock firmware can inject arbitrary PDUs.
11_max_fidelity.py | Identity spoofing (InitA clone) | Claims InitA FF:EE:DD:CC:BB:AA via set_bd_address, raw-injects the literal packet 5x, then connects with custom LLData and enumerates GATT.
12_ab_diagnose.py | Parameter-tolerance diagnosis | A/B tests default vs custom LLData (AA/CRC/chanmap/hop) and sweeps intervals 80/160/320 ms to find which non-compliant parameters get the link killed.
13_death_autopsy.py | Post-mortem / crash forensics | Hooks on_disconnected, on_ctl_pdu and on_data_pdu to dump LL control PDUs and decode HCI termination reasons (0x08 timeout, 0x13 remote terminated, 0x3E LL response timeout, etc.).
14_mtu_responder.py | Link keep-alive exploit | Intercepts ATT_EXCHANGE_MTU_REQ (L2CAP CID 0x0004, ATT 0x02) and answers a raw MTU Response (247) in milliseconds, stopping the peripheral's ~200 ms LL_TERMINATE_IND kill.
15_manual_att.py | Raw ATT stack / ATT fuzzing | Hand-builds L2CAP+ATT frames inside LL data PDUs, tests 4 TX formats, then runs By-Group-Type (0x10) and By-Type (0x08) discovery completely below the host GATT stack.
oooooooooooo.py | DoS - length-field fuzzer (SweynTooth) | Fork of the rogue-central framework that declares N payload bytes in the header while truncating the buffer (CC2540 CVE-2019-19194 style) and uses ADV-gap timing to detect crashes/reboots.
own_packet_full.py | Full rogue-central framework | 8-step pipeline: environment audit, scan + address-type detect, build/verify CONNECT_IND, raw inject, InitA spoof, custom connect, 3 ms MTU-response pump, manual GATT discovery.
sweyntooth_crash.py | DoS - malformed CONNECT_IND crasher | Fires 9 named SweynTooth vectors (trunc0/12/18/26, iv0, to0, hop0, over247, valid34) with an ADV-interval oracle to detect firmware crashes, deadlocks and resets.
ble_busy.py | DoS - link saturation | Infinite loop of fast BleakClient connect/disconnect (0.5 s timeout, 0.05 s gap) that keeps the target's Link Layer busy so legitimate centrals cannot connect.
pairing_req_multiple.py | DoS - pairing flood | Fires rapid pairing/connection requests (0.3 s timeout, 0.02 s gap) until the first successful connect, then holds that single link stable forever and silently reconnects if it drops.
ble_connection_time_checker.py | Uptime / crash monitor | Connects, holds the link, logs exact connect/disconnect timestamps and session duration, reconnects every 2 s to catch watchdog reboots and instability under test.
getting-all-details-of-ble.py | Recon - GATT enumeration | Connects and dumps every service, characteristic (UUID, handle, properties), readable value (hex/UTF-8) and descriptor in a tree; pre-attack attack-surface mapping.
read_descriptors.py | Recon - descriptor extraction | Reads raw GATT descriptor bytes at fixed handles (default 19, 22) and prints repr + ASCII to check for improper access controls.
thor.py | GATT write fuzzer | Explores all services, then sweeps write lengths 1..MTU-3 over every writable characteristic with checkpoint resume, drop reconnects, hang detection, notification capture and ATT error classification.
check.sh | Environment doctor | Runs 12 lab checks (ButteRFly USB c0ff:eeee, /dev/ttyACM0, pyserial, ModemManager off, uucp group, whad, Sniffle, extcap, arm-none-eabi-gcc, wireshark, nrfutil, wble-central); exit code = number of failures.

# 1. CORE LAB SCRIPTS - LINK LAYER (need the WHAD dongle)
################################################################################

1_build_packet.py | Packet crafting (offline) | Builds a byte-exact 36-byte CONNECT_IND with custom AA/CRCInit/interval/hop/channel-map and runs spec legality checks | None - pure Python stdlib, no radio
2_send_packet.py | Rogue central / hijack | Connects to the target with attacker-chosen Link Layer parameters and proves the rogue-parameter link carries GATT | [DONGLE] + [TARGET]
4_inject_raw.py | Reactive LL injection | Arms the injector with 4 trigger strategies to fire a raw CONNECT_IND inside the advertising inter-frame space | [DONGLE] + [TARGET]
5_scan_then_inject.py | Synchronized hijack | Scans to confirm advertising, reopens as injector, arms AdvA triggers, watches for the connection to be taken | [DONGLE] + [TARGET]
6_scan_inject_final.py | Low-latency connection race | Single-instance continuous RX that counts target ADVs and arms triggers without a dongle reopen | [DONGLE] + [TARGET]
7_connect_lifecycle.py | Hijack + acceptance oracle | Injects CONNECT_IND on ADV detection and measures the ADV silence gap to confirm the 2 s supervision timeout was obeyed | [DONGLE] + [TARGET]
8_trigger_sweep.py | Injector calibration | Sweeps AdvA pattern byte offsets 0-30 to find the offset that makes reactive injection fire reliably | [DONGLE] + [TARGET]
10_prepare_rootcause.py | Injection root-cause probe | Wraps the raw packet as BTLE/BTLE_DATA so prepare() accepts it, then compares manual TX vs ReceptionTrigger | [DONGLE] + [TARGET]
11_max_fidelity.py | Identity spoofing (InitA clone) | Claims InitA FF:EE:DD:CC:BB:AA, raw-injects the packet 5x, then connects with custom LLData and enumerates GATT | [DONGLE] + [TARGET]
12_ab_diagnose.py | Parameter-tolerance diagnosis | A/B tests default vs custom LLData and sweeps 80/160/320 ms intervals to find which parameters kill the link | [DONGLE] + [TARGET]
13_death_autopsy.py | Post-mortem / crash forensics | Dumps LL control PDUs and decodes HCI termination reasons while the link idles | [DONGLE] + [TARGET]
14_mtu_responder.py | Link keep-alive exploit | Intercepts ATT_EXCHANGE_MTU_REQ and answers a raw MTU Response (247) to stop the ~200 ms LL_TERMINATE_IND kill | [DONGLE] + [TARGET]
15_manual_att.py | Raw ATT stack / ATT fuzzing | Hand-builds L2CAP+ATT frames inside LL data PDUs and runs service/characteristic discovery below the host stack | [DONGLE] + [TARGET]
oooooooooooo.py | DoS - length-field fuzzer | Declares N payload bytes while truncating the buffer (CC2540 CVE-2019-19194 style) and uses ADV-gap timing to detect crashes | [DONGLE] + [TARGET]
own_packet_full.py | Full rogue-central framework | 8-step pipeline: audit, scan, build/verify packet, inject, spoof InitA, custom connect, MTU pump, manual GATT discovery | [DONGLE] + [TARGET]
sweyntooth_crash.py | DoS - malformed CONNECT_IND crasher | Fires 9 named SweynTooth vectors (trunc0/12/18/26, iv0, to0, hop0, over247, valid34) with an ADV-interval crash oracle | [DONGLE] + [TARGET]
